# 原 CustomModel 与空间修正版：10 组患者划分配对实验

此目录独立保存本实验的代码和输出。原有 `data/patient_split_clean/`、四个已训练运行目录、Grad-CAM 结果及模型定义不会被覆盖。

## 固定设计

- 划分种子：1001–1010，各生成一组新的患者级 Clean 训练/验证/测试划分。类别内分别打乱患者，比例约 70%/20%/10%，与现有数据准备脚本同一规则。
- 每组只从其训练图像计算 RGB 标准化参数。两版模型共用该组的划分和参数。
- 训练种子固定 24；两版模型在每组分别重置随机状态，验证初始权重相同。
- ImageNet 预训练 ResNet-50 主干，Adam `3e-5`，交叉熵，请求批大小 32，最多 100 轮，验证损失 7 轮不改善早停。HCC=0、血管瘤=1。
- 主指标为患者级平衡准确率；同时报告患者准确率、HCC 召回率、血管瘤特异度、AUC、Brier 分数及图像级指标。
- 种子 24 的已有实验仅作为先导结果，不纳入这 10 组汇总。

## 运行

在项目根目录，用既有 `yolov5` GPU 环境：

```powershell
& 'C:\Users\lhx\miniconda3\envs\yolov5\python.exe' -u patient_split_comparison\run_study.py
```

可先运行 `--prepare-only` 检查全部划分及标准化，或用 `--seed 1001` 只运行一组。重复同一命令会跳过已完成模型并从检查点恢复未完成模型。输出在 `outputs/`，各组的患者/图像分配、归一化、运行配置、检查点、逐图像及逐患者预测、评估图表与配对汇总均保留。运行时将控制台输出重定向到 `outputs/study.log` 可用于长期监控。

10 组测试集之间会共享部分患者，因此跨组差值反映对患者划分的敏感程度，不等于外部数据集的独立验证。原版与修正版的差异同时包含“保留 7×7 分支特征”和“空间注意力能够按位置加权”，并非单独的空间注意力消融。
